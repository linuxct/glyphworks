# Pipeline core

Portable Kotlin/JVM pipeline model, bounded JSON codec, interpreter, scene and
sprite primitives. No Android, Compose, GlyphWorks or Nothing SDK dependency.

See [SDK integration](../docs/pipeline-sdk.md),
[JSON format](../docs/glyph-pipeline-format.md) and the independent
[`pipeline-consumer`](../pipeline-consumer) fixture. This module uses the
repository's existing license.
