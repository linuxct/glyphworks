# Pipeline Android adapter

API 26+ scheduling adapter for `pipeline-core`. The host supplies the Handler,
permissions, data sources and output device. The AAR depends on the core JAR;
Maven dependency metadata is part of the SDK distribution.

See [SDK integration](../docs/pipeline-sdk.md) and the minified
[`pipeline-android-consumer`](../pipeline-android-consumer) fixture. This module
uses the repository's existing license.
